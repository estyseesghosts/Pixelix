# unnamed - a mobile sharkey client (and a fork of pixelix)

![Preview of App](https://github.com/ghostbyte-dev/pixelix/blob/5687e50de0f986d5d043d58d2518740c3ef0e0c6/assets/pixelix_screenshots.png)

i don't like pixelfed. i don't want to use pixelfed. i think the fediverse was designed backwards in a way that breaks the interconnectivity that should make it great. i would love to bring one account across multiple apps, even at the cost of losing certain platform specific features. i think in the future the network could be designed at the protocol level for this kind of interoperability, but that's another day's problem. 

this fork serves to solve my problem today. which is that i want a photo centric app for the fediverse, without having to keep track of a million accounts. i can use it with the one i already have. all love to the original developers of this app! this is unfinished and might not ever be stable.
